Esta vista representa los valores recibidos desde el sensor (ejes X e Y) como una posición dentro de una cuadrícula de {{ tamano_grilla }} × {{ tamano_grilla }} celdas. La columna activa depende del valor de X y la fila activa depende del valor de Y: mientras más se inclina el sensor hacia un lado, la celda iluminada se desplaza en esa dirección. La fila y la columna completas se marcan en un tono tenue, y la celda exacta brilla con una animación pulsante. La página se actualiza sola cada 3 segundos para reflejar nuevas lecturas, sin usar JavaScript.
